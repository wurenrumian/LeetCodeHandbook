十个专题，每个都是一份"可背诵模板 + 变体清单"。顺序建议按下面从易到难，每个专题读完后立刻去 [题目索引](/problems/) 挑同标签的题刷。

## 怎么选专题

拿到一道题，先别想"用什么算法"，先看这几个问题：

1. **数据有序吗？或者答案有单调性吗？**
   有序 + 求某个位置 → 二分。答案空间有单调性（"能"之后一定一直"能"）→ 二分答案。

2. **要找的东西是"连续的"吗？**
   子串、子数组、连续区间 → 滑动窗口。窗口的两个端点都只往右走，这是它能做到 O(n) 的唯一原因。

3. **需要"记住见过什么"吗？**
   判断存在性、统计频次、分组 → 哈希表。代价是 O(n) 空间。

4. **是"从已有状态推下一个状态"吗？**
   能用前面的结论算出后面的 → DP。关键不是"看起来复杂"，而是**子问题会不会被重复求解**。

5. **要枚举所有方案吗？**
   所有排列、所有组合、所有路径 → 回溯。写之前先想清楚"决策树的每一层在决策什么"。

6. **问"最少几步""按层"？**
   边权全为 1 → BFS。问"连不连通""有没有环" → DFS。

## 专题之间的关系

这几个专题不是并列的，它们经常组合出现：

- **哈希表 + 链表** → LRU 缓存（146）：哈希负责 O(1) 定位，链表负责 O(1) 维护顺序
- **单调栈 + 数组** → 每日温度（739）：栈里存的是**下标**，不是值
- **BFS 与 DFS 的分工**：BFS 求**最短**，DFS 求**是否存在/连通**。同一个网格题，两者都能做，但复杂度与栈深差别很大

## 每个专题页有什么

- **统一模板**：能背下来的骨架，注释标出"这里可以改"
- **变体清单**：同一模板在不同条件下的改法，附带"改哪一行"
- **适用信号**：题目描述里出现什么词时该想到它
- **坑点汇总**：不是零散记录，而是按"改错会怎样"分类

## 一个提醒

模板的价值在于**减少你要现场决策的次数**，不在于背下字符。真正需要判断的永远只有两三处：

- 区间是左闭右闭还是左闭右开？
- 循环条件是 `<` 还是 `<=`？
- 收缩边界时是 `= mid` 还是 `= mid + 1`？

把这三处想清楚，其余都是机械翻译。每道题的"模板对照"就是在练这三处。
