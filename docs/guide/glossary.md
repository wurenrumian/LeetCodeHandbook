# 术语表

全站只有一种写法。同一个概念在两个页面上叫两个名字，读者就得自己判断"这两个说的是不是一回事"——那不是他该干的活。

这张表是**唯一来源**：页面正文里出现的术语，写法以此为准；改术语只改这里，然后靠 `npm run check` 找出没跟上的页面。

## 区间与指针

| 写法 | 一句话定义 | 详解 |
|---|---|---|
| 左闭右开 `[left, right)` | 左端可取、右端不可取的区间。`left == right` 时为空 | [二分](/topics/binary-search/) |
| 左闭右闭 `[left, right]` | 两端都可取。`left > right` 时为空 | [二分](/topics/binary-search/) |
| 不变式 | 循环或递归**全程为真**的那句话，是模板能写对的根据 | 每页速查卡第一行 |
| 边界收缩 | 根据比较结果排除一段候选，改的是 `left` 或 `right` | [二分](/topics/binary-search/) |

## 二分的三个决策点

这三处必须成套出现，混搭就会死循环或漏解：

| 决策点 | 取值 |
|---|---|
| 区间约定 | `[left, right)` 或 `[left, right]` |
| 循环条件 | `left < right` 或 `left <= right` |
| 边界更新 | `right = mid` 或 `right = mid - 1` |

三者不是"哪个更好"，是**配套关系**：开区间配 `right = mid`，闭区间配 `right = mid - 1`。全站统一用左闭右开。

## DP

| 写法 | 一句话定义 | 详解 |
|---|---|---|
| 状态定义 | `dp[i]` 里 `i` 到底是什么，是整个 DP 的第一步 | [动态规划](/topics/dp/) |
| 完全背包 | 每种物品可用无限次，容量**正序**遍历 | [322](/topics/dp/322-coin-change) |
| 0-1 背包 | 每种物品最多用一次，容量**倒序**遍历 | [动态规划](/topics/dp/) |
| 哨兵值 | 表示"不可达"的那个值。用 `INT_MAX` 必须判可达，用具体上界（如 `amount + 1`）不用判 | [322](/topics/dp/322-coin-change) |
| 遍历顺序 | 外层物品还是外层容量，决定"组合数"还是"排列数" | [动态规划](/topics/dp/) |

## 图与树

| 写法 | 一句话定义 | 详解 |
|---|---|---|
| 邻接表 | `graph[u]` 存 `u` 的所有邻居，是图的标准存法 | [图的遍历 · DFS](/topics/graph-dfs/) |
| 层界快照 | 进 `for` 之前把本层节点数存下来，之后队列怎么变都不影响本层处理 | [树的遍历 · BFS](/topics/graph-bfs/) |
| 三色标记 | `0` 未访问 / `1` 栈上 / `2` 完成。只有第三种状态才能区分"汇合"和"环" | [207](/topics/graph-dfs/207-course-schedule) |
| 原地标记 | 直接改写输入本身当标记（如把 `'1'` 改成 `'0'`），省掉 `visited` 数组 | [200](/topics/graph-dfs/200-number-of-islands) |
| 连通块 | 互相可达的点集。外层扫每一个点，每起一次 DFS 就是一块 | [200](/topics/graph-dfs/200-number-of-islands) |

## 禁止写法

改叫法的时候，容易顺手写出"意思一样但不统一"的表达。这张表就是拿来自动检查的——检查脚本读它，正文里出现右列任何一个写法都会报错。

| 唯一写法 | 禁止写成 |
|---|---|
| 左闭右开 | 半开区间, 左开右闭 |
| 左闭右闭 | 双闭区间, 闭区间表示 |
| 三色标记 | 三色染色, 三态标记 |
| 层界快照 | 层宽快照, 层大小快照 |
| 原地标记 | 就地标记, 原地染色 |
| 归一化 key | 标准化 key, 规范化 key |
