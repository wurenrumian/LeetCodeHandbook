**文件**：`docs/.vitepress/theme/data/problems.ts`（16 条 `link` 字段）

  /topics/binary-search/704-binary-search        ← 无 .html
  /topics/sliding-window/3-longest-substring     ← 无 .html

对比：侧边栏和正文 Markdown 链接经 VitePress 处理后会**自动补 `.html`**（因 `cleanUrls: false`）：

```

正文链接:  /guide/conventions.html#加一道新题的清单              ✅
problems:  /topics/binary-search/34-first-last-position        ❌ 无扩展名

**实测**（纯静态服务器指向 `dist/`，不做任何 rewrite）：

```

/topics/binary-search/704-binary-search.html  200
/topics/dp/322-coin-change                    404
/topics/dp/322-coin-change.html               200

**影响面**：题目索引页 `/problems/` 的 12 条可点击题目链接。它是站点三大入口之一。

**建议**（任选其一）：

1. **最省事**：`problems.ts` 的 `link` 一律带 `.html`，与 VitePress 自身输出一致。SPA 内跳转 URL 会带 `.html`，与侧边栏一致，无副作用。
2. **改配置**：`cleanUrls: true`，构建去掉 `.html`，links 保持现状即正确，服务器只需 `try_files $uri $uri/ /index.html`。
3. **只改运维**：确保 nginx 严格使用 `README.md:19` 的 `try_files $uri $uri/ $uri.html /index.html;` 建议把这一行在 README 里标成"不可省略"。

> 判定说明：构建本身完全正确，风险全在"产物 + 服务器配置"的组合上。因索引页是主入口，按 P0 报。

## P1 缺陷

### P1-1 移动端表格横向溢出，整页可左右拖动

**文件**：`docs/.vitepress/theme/custom.css:175-181`

**根因**：该规则覆盖掉了 VitePress 的表格滚动容器。

```css
/* custom.css:175 现状 */
.vp-doc table {
  display: table;      /* ← 覆盖了 VitePress 的 display: block */
  width: 100%;
  /* 缺 overflow-x: auto */
}

/* VitePress 默认（node_modules/.../vp-doc.css:166） */
.vp-doc table {
  display: block;
  overflow-x: auto;    /* ← 随 display:table 一起失效 */
}
```

`display: table` 让表格按内容撑开而不受容器约束，`overflow-x` 随之失效，表格把整页顶出去。

**实测**（headless Chrome，CDP 量 `documentElement.scrollWidth - clientWidth`）：

| 视口 | 溢出页数 | 最严重 |
|---|---|---|
| 1440 / 1024 / 900 | 0 | — |
| 480 | 1 | `/topics/backtracking/78-subsets` +18px |
| 390 | 9 | `/topics/backtracking/78-subsets` +107px |
| 360 | 11 | `/topics/backtracking/78-subsets` +137px |

超宽表格明细（容器 342px @ 390 视口）：

```
/topics/backtracking/78-subsets       table 473px  (+131)
/topics/stack/739-daily-temperatures  table 438px  (+96)
/topics/hash-table/49-group-anagrams  table 426px  (+84)
/topics/binary-search/                table 421px  (+79)
/problems/                            table 370px  (+28)
```

截图确认：390px 下 `/topics/binary-search/` 的"三种写法"表格，「收缩」列整列跑到屏幕外，`left = mid + 1 / right = mid - 1` 被切成多行碎片。

**建议**：

```css
@media (max-width: 767px) {
  .vp-doc table {
    display: block;
    overflow-x: auto;
    -webkit-overflow-scrolling: touch;
  }
}
```

或更稳：保留 `display: block`，只覆盖样式属性（`border-collapse`/`font-size`/`margin`），删掉 `display: table` 与 `width: 100%`。

> 补充：`/problems/` 的 `.pi-table` 吃同一个坑（`ProblemIndex.vue:280` 又写了一条 `display: table`），需一并处理。
